ScriptPlayer+ 0.7.0 정식 버전이 공개되었습니다. 모션 설정을 영상마다 저장하고, 스크립트 연결과 라이브러리 분류를 더 편하게 관리할 수 있습니다.

## 모션 설정과 스크립트 연결

- **축별 반응 곡선:** 각 축의 진폭, 출력 범위, 반응 곡선을 따로 조절합니다. 선형, 계단형, 로그, 다항식, 제곱근, tanh 압축 곡선을 미리보기로 확인할 수 있습니다. tanh는 움직임을 증폭할 때 상한에 가까워지는 구간을 부드럽게 눌러 줍니다.
- **영상별 모션 설정:** 전역 설정과 현재 영상 전용 설정을 전환합니다. 빠른 스트로크 조절과 설정 화면에도 같은 선택 범위가 적용됩니다.
- **스크립트 연결 기억:** 직접 선택하거나 끌어 놓은 스크립트를 영상마다 기억합니다. 파일 이름을 바꿀 필요가 없으며, 재생목록을 내보내고 다시 가져와도 직접 지정한 스크립트 연결이 유지됩니다.

## 재생과 Handy 연결 개선

자막 탐색이 끝나기 전에도 스크립트를 적용합니다. Handy 출력이 실제 재생 상태와 버퍼링, 탐색에 맞춰 동작하도록 개선했으며, 다음 항목 자동 재생과 영상·오디오 반복에도 적용됩니다. 사용자가 직접 정지한 출력은 다시 시작하기 전까지 멈춘 상태를 유지합니다.

HSSP CSV 타이밍과 실패 진단·복구, FFmpeg·HLS 진단 및 재시도도 개선했습니다.

## 라이브러리 정리

- 태그와 스마트 그룹으로 영상을 분류합니다.
- 파일을 지우지 않고 라이브러리 항목만 제외하거나 복원할 수 있습니다.
- 휴지통으로 보낼 때 함께 처리할 스크립트를 개별 선택할 수 있습니다.
- 모던·클래식 화면과 파일 목록의 썸네일 캐시, 정보 표시, 조작 버튼을 다듬어 작은 창에서도 사용하기 편하게 했습니다.

## 사용 전에 알아둘 점

영상별 설정, 스크립트 연결, 태그는 파일 경로를 기준으로 저장됩니다. 앱 밖에서 파일 이름을 바꾸거나 이동하면 자동으로 따라가지 않습니다. **Range Extender는 영상별 모션 설정에 포함되지 않습니다.** 일부 새 항목은 한국어와 영어로만 표시됩니다.

Handy는 새 스크립트 준비를 마친 뒤 현재 영상 위치에 맞춰 합류하므로, 다른 영상으로 넘어갈 때 준비 시간이 생길 수 있습니다. 네이티브 반복은 업로드한 스크립트를 재사용하지만 클라우드 재생 명령이 필요합니다. 반복 경계에서 실제 움직임이 끊기지 않는다고 보장하지는 않습니다.

## 다운로드와 업데이트

정식 자동 업데이트 대상은 0.7.0입니다. 직접 설치할 때는 운영체제에 맞는 파일을 선택하세요.

- **Windows x64:** Setup 설치 파일 또는 ZIP
- **macOS Apple Silicon:** arm64 DMG 또는 ZIP
- **Linux x64:** AppImage, DEB 또는 TAR.GZ

원본 릴리스에는 파일 확인용 `SHA256SUMS.txt`도 제공합니다.
