특정 스크립트에서 `HSSP setup failed: error loading stream data` 오류가 발생하는 문제를 수정한 **Windows 테스트 버전**입니다. GitHub Pre-release로 제공하며, 정식 자동 업데이트 대상은 0.7.0을 유지합니다.

## 수정 내용

해당 로딩 오류가 발생하면 스크립트 시작 전 고정 위치 구간에 같은 위치의 보조점 하나를 추가하고 **한 번 자동 재업로드**합니다. 기존 타임스탬프와 위치, 시작 전 대기 구간은 그대로 유지합니다. 정상적으로 로딩되는 스크립트는 기존 방식으로 처리합니다.

진단 정보에는 실제 전송 데이터 크기와 보정 적용 여부가 추가되었습니다.

## 확인한 범위

공식 릴리스의 확인 결과에 따르면, 제보 스크립트는 실제 Handy에서 기존 방식으로 5회 모두 준비에 실패했고 수정 후에는 3회 연속 준비에 성공했습니다. **확인은 업로드와 HSSP 준비 단계까지이며, 실제 움직임 재생은 검증에 포함되지 않았습니다.**

## 테스트 방법

1. 기존 설치본을 유지한 채 Windows x64 ZIP을 별도 폴더에 압축 해제합니다.
2. 다른 플레이어 실행 창을 닫고 `ScriptPlayerPlus.exe`를 실행합니다.
3. 문제가 있던 영상과 스크립트를 열어 준비 완료와 실제 Handy 움직임을 확인합니다.
4. 일시정지 후 재개, 반복, 다음 재생목록 항목으로 이동할 때의 동작을 확인합니다.
5. 문제가 남아 있으면 복사한 진단 정보와 재현 상황을 함께 전달해 주세요.
