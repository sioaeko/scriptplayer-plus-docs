ScriptPlayer+ 0.7.2 정식 버전이 공개되었습니다. 재생 중 세기 조절과 파일 탐색이 편해졌고, 별점을 백업할 수 있습니다.

## 새 기능

- **스트로크 최소·최대값 단축키:** 스트로크 하한과 상한을 각각 낮추고 높이는 동작에 키보드 키와 게임패드 버튼을 따로 지정합니다. 한 번 누를 때마다 해당 끝값이 5%포인트씩 바뀝니다. 새 동작은 기본적으로 지정되지 않은 상태이며, 게임패드는 스틱이 아닌 버튼만 쓰고 길게 눌러도 반복되지 않습니다.
- **파일 목록 영상 미리보기:** **설정 → 외관**에서 **영상 미리보기**를 켜면, 메인 재생이 정지되거나 일시정지된 동안 다른 영상 위에 마우스를 올려 소리 없이 미리 봅니다. 기본값은 지금처럼 정지 썸네일입니다.
- **별점 내보내기·가져오기:** **설정 → 복구**에서 별점을 백업하고 되살립니다. 가져오기는 직접 지운 별점을 포함해 기존 별점을 유지합니다. 백업에는 미디어를 구분하는 값이 들어가 파일 경로가 포함될 수 있지만, 장치 연결 정보는 들어가지 않습니다.
- **명령줄로 열기:** 앱을 시작할 때나 실행 중일 때 명령줄로 미디어나 펀스크립트 파일을 엽니다. 미디어를 여러 개 넘기면 재생목록이 되고 첫 항목이 일시정지 상태로 열립니다.
- **HereSphere 연동(베타):** 재생, 탐색, 배속을 HereSphere와 맞춥니다. 실제 헤드셋 재생과 장치 동기화는 아직 검증되지 않았습니다.
- **L0를 속도로 사용:** Hismith 같은 Intiface Scalar·Oscillate 장치에 속도용 스크립트의 값을 그대로 보냅니다. 일반 위치 스크립트를 이동 속도로 바꾸지는 않습니다. 실제 Hismith 동작은 아직 검증되지 않았습니다.

## 수정과 개선

- 스크립트 없는 파일 제외에 WAV, MP3, M4A 같은 오디오 항목도 포함합니다. 스크립트가 있거나 직접·축별로 연결한 항목은 남기며 원본 파일은 삭제하지 않습니다.
- Handy 자동 연결을 켜 두면 디바이스 화면을 열지 않아도 앱을 시작할 때 연결합니다. 직접 연결을 끊은 경우는 그대로 둡니다.
- 축 녹화 슬라이더의 반응을 개선하고, 긴 녹화에서 메모리 사용을 줄였습니다. 녹화 데이터에 보간한 점을 더하지는 않습니다.
- 재생과 일시정지를 빠르게 바꿀 때의 문제, 속도형 장치의 정지·재시도, 장치 진단 정보 복사를 고쳤습니다.
- 새 기능의 한국어, 영어, 일본어, 중국어 문구를 반영했습니다.
- 공개된 보안 권고에 따라 Electron과 관련 실행·빌드 의존성을 업데이트했습니다. 앱 안에 무결성 검사 기능이 추가된 것은 아닙니다.

## 호환성 안내

**FunOSR SR1 3.0은 호환성을 확인할 기술 문서가 아직 없어 이번 버전의 지원 장치 목록에 추가하지 않았습니다.** 기존 연결 방식과 호환된다거나 호환되지 않는다는 뜻은 아닙니다.

게임패드 동작은 시뮬레이션 입력으로 시험했으며, 실제 컨트롤러와 장치 동작은 아직 검증되지 않았습니다. 앱에서도 HereSphere에 베타 표시가 붙어 있습니다.

## 다운로드

- **Windows x64:** Setup 설치 파일 또는 ZIP
- **macOS Apple Silicon:** arm64 DMG 또는 ZIP
- **Linux x64:** AppImage, DEB 또는 TAR.GZ

macOS 빌드는 임시 서명만 되어 있고 공증을 받지 않았습니다. 원본 릴리스에는 파일 확인용 `SHA256SUMS.txt`도 제공합니다.
