ScriptPlayer+ 0.7.0 is now available. You can save motion settings for each video and manage script links and library categories more easily.

## Motion settings and script links

- **Per-axis response curves:** Adjust amplitude, output range and response curve separately for each axis. Linear, stepped, logarithmic, polynomial, square-root and tanh compression curves can be checked in a preview. tanh softly compresses the part that approaches the upper limit when you amplify motion.
- **Per-video motion settings:** Switch between global settings and settings for the current video only. The same scope applies to quick stroke adjustment and the settings screen.
- **Remembered script links:** Scripts you select or drag in by hand are remembered for each video. There is no need to rename files, and manually assigned script links survive exporting and re-importing a playlist.

## Playback and Handy improvements

Scripts are applied before subtitle discovery finishes. Handy output now follows the actual playback state, buffering and seeking, including auto-play of the next item and video or audio looping. Output you stop yourself stays stopped until you start it again.

HSSP CSV timing, failure diagnostics and recovery, and FFmpeg and HLS diagnostics and retries have also been improved.

## Library organization

- Sort videos with tags and smart groups.
- Exclude or restore library entries without deleting the files.
- Choose individually which scripts to send to the Trash along with a video.
- The modern and classic layouts and the file list have refined thumbnail caching, info display and controls, so they are easier to use in a small window.

## Before you start

Per-video settings, script links and tags are saved by file path. If you rename or move a file outside the app, they do not follow it. **Range Extender is not part of the per-video motion settings.** Some new items are shown only in Korean and English.

Handy joins at the current video position after it finishes preparing a new script, so there may be a short preparation time when you move to another video. Native looping reuses the uploaded script but needs cloud playback commands. Uninterrupted motion at the loop boundary is not guaranteed.

## Download and update

0.7.0 is the release delivered by automatic updates. When installing manually, choose the file for your operating system.

- **Windows x64:** Setup installer or ZIP
- **macOS Apple Silicon:** arm64 DMG or ZIP
- **Linux x64:** AppImage, DEB or TAR.GZ

The original release also includes `SHA256SUMS.txt` for verifying files.
