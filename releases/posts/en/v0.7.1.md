ScriptPlayer+ 0.7.1 is now available. You can play scripts with no video and record motion yourself to save it.

## New features

- **Script-only playback:** **Open script only** in the file list plays a funscript on its own, with no video or black screen. Repeat playback works too.
- **Axis recording:** In **Script tools → Record axis**, record one axis with a slider while media plays, preview the result and save it as a separate funscript. This records slider input, not physical device movement. Save your take before closing the app.
- **Cover art FIT / FILL:** FIT and FILL now apply to cover art on the audio playback screen.
- **Remove videos without scripts:** Take every unscripted video out of the playlist at once, after a count and confirmation. Original files are not deleted, and audio and videos with manual or per-axis script links stay. Works in both the modern and classic UI.
- **Per-video settings recovery:** Per-video axis settings are found again after a file is renamed or moved on the same disk. The file must first have been opened in this version; copies to another disk and files modified in place are not matched automatically.
- **Hide playback warnings:** Dismiss advisory playback warnings for the current media only, or hide them for good in **Settings → Playback**. Actual errors and diagnostics stay available.

## Fixes and improvements

- Includes the Handy HSSP stream-data loading recovery from 0.7.1-beta.1, which keeps the initial hold and tries recovery once.
- Refreshing or reloading scripts keeps the axis and length of script-only playback, and existing audio boost settings.
- Fixed old ratings being applied to another file that only shared its name and modification time.
- Polished native controls and missing translations, and matched the Linux desktop launcher to the running app.

## What was verified

In-place installation on Windows and preservation of existing settings and library data were verified. One Handy was tested on Windows for automatic next-video playback, repeat playback, output stop and resume, and stop persistence across loops. New scripts still need preparation time, and uninterrupted physical motion at loop boundaries is not guaranteed. macOS builds use ad hoc signing and are not notarized.
