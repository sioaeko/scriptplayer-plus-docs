ScriptPlayer+ 0.7.2 is now available. Adjusting strength during playback and browsing files are easier, and you can back up your ratings.

## New features

- **Stroke minimum and maximum shortcuts:** Assign separate keyboard keys and gamepad buttons to lower and raise the stroke lower and upper limits. Each press moves that limit by five percentage points. New actions start unassigned; gamepads use buttons rather than sticks, and holding a button does not repeat.
- **Video preview in the file list:** Turn on **Video preview** in **Settings → Appearance**, then hover over another video while main playback is stopped or paused to see a silent preview. The default stays Still thumbnail.
- **Export and import ratings:** Back up and restore ratings in **Settings → Recovery**. Import keeps your existing ratings, including ones you cleared. Backups contain keys that identify media and can include file paths, but no device credentials.
- **Open from the command line:** Open media or funscript files from the command line at startup or while the app is running. Several media files become a playlist and the first item opens paused.
- **HereSphere integration (beta):** Keeps playback, seeking and speed in step with HereSphere. Playback on a physical headset and physical device synchronization are not yet verified.
- **L0 as speed:** Sends values from speed scripts as they are to Intiface Scalar and Oscillate devices such as Hismith. It does not turn ordinary position scripts into movement speeds. Physical Hismith operation is not yet verified.

## Fixes and improvements

- Remove files without scripts now includes audio entries such as WAV, MP3 and M4A. Scripted and manually or per-axis linked entries stay, and original files are not deleted.
- With Handy auto-connect on, the app connects at startup without the Device screen being opened. A manual disconnect is respected.
- Improved axis-recording slider feedback and reduced memory use in long recordings, without adding interpolated points to the recording.
- Fixed rapid play and pause switching, stop and retry for speed devices, and copying device diagnostics.
- Updated the Korean, English, Japanese and Chinese text for the new features.
- Updated Electron and affected runtime and build dependencies to address published security advisories. This release does not add an in-app integrity scanner.

## Compatibility

**FunOSR SR1 3.0 has not been added to the supported-device list in this release, because the technical documentation needed to confirm compatibility is not yet available.** This does not mean it is either compatible or incompatible with existing connection modes.

Gamepad behavior was tested with simulated input; real controllers and physical devices are not yet verified. HereSphere is labelled Beta in the app as well.

## Downloads

- **Windows x64:** Setup installer or ZIP
- **macOS Apple Silicon:** arm64 DMG or ZIP
- **Linux x64:** AppImage, DEB or TAR.GZ

macOS builds use ad hoc signing and are not notarized. The original release also includes `SHA256SUMS.txt` for verifying files.
