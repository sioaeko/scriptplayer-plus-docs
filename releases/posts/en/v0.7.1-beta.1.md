This **Windows test build** fixes the `HSSP setup failed: error loading stream data` error that occurs with certain scripts. It is offered as a GitHub pre-release, and automatic updates stay on 0.7.0.

## What is fixed

When this loading error occurs, the app adds one helper point at the same position to the fixed-position stretch before the script starts, then **re-uploads automatically once**. Existing timestamps, positions and the wait before the start are kept as they are. Scripts that load normally are handled the same way as before.

The diagnostics now include the actual size of the data sent and whether the correction was applied.

## What was verified

According to the checks in the official release, the reported script failed to prepare on a real Handy in all 5 attempts with the previous method, and prepared successfully 3 times in a row after the fix. **The checks cover the upload and HSSP preparation steps only; actual motion playback was not verified.**

## How to test

1. Keep your existing installation and extract the Windows x64 ZIP into a separate folder.
2. Close any other player windows and run `ScriptPlayerPlus.exe`.
3. Open the video and script that had the problem, and check that preparation completes and the Handy actually moves.
4. Check the behavior when you pause and resume, loop, and move to the next playlist item.
5. If the problem remains, send the copied diagnostics together with how to reproduce it.

This beta is **available only as a Windows x64 ZIP, with no Setup installer.** Download it manually from the official release below.
