这是修复特定脚本出现 `HSSP setup failed: error loading stream data` 错误的 **Windows 测试版**。它以 GitHub 预发布（Pre-release）形式提供，正式自动更新仍为 0.7.0。

## 修复内容

出现该加载错误时，会在脚本开始前的固定位置区段加入一个相同位置的辅助点，并**自动重新上传一次**。原有的时间戳、位置和开始前的等待区段保持不变。能正常加载的脚本仍按原方式处理。

诊断信息中新增了实际发送的数据大小以及是否应用了修正。

## 验证范围

根据官方发布中的验证结果，所报告的脚本在真实 Handy 上用原方式 5 次全部准备失败，修复后连续 3 次准备成功。**验证仅覆盖上传和 HSSP 准备阶段，未包含实际运动播放。**

## 测试方法

1. 保留现有安装，将 Windows x64 ZIP 解压到单独的文件夹。
2. 关闭其他播放器窗口，运行 `ScriptPlayerPlus.exe`。
3. 打开出现问题的视频和脚本，确认准备完成以及 Handy 实际运动。
4. 确认暂停后继续、循环以及切换到播放列表下一项时的表现。
5. 如果问题仍然存在，请将复制的诊断信息连同复现情况一起发送给我们。

本测试版**仅提供 Windows x64 ZIP，没有 Setup 安装程序。** 请从下方官方发布手动下载。
