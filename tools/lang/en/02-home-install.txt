Linux<a aria-label="Link to this section" class="anchor" href="#install-linux">#</a>
«ko»
Ubuntu / Kubuntu 24.04 이상은 <strong>DEB 패키지를 쓰는 것을 권장</strong>합니다.
              이 버전들은 권한 없는 사용자 네임스페이스를 제한하는데, Chromium 샌드박스가 동작하려면
              실행 파일 전용 AppArmor 프로필이 필요하고 그 프로필은 DEB 패키지에만 들어 있습니다.
«t»
On Ubuntu / Kubuntu 24.04 and newer, <strong>use the DEB package</strong>.
              Those releases restrict unprivileged user namespaces, and the Chromium sandbox needs an
              executable-scoped AppArmor profile to work — a profile that ships only in the DEB.
«ko»
<strong>DEB</strong> — AppArmor 프로필을 함께 설치합니다. 24.04 이상에서 가장 안전한 선택입니다.
«t»
<strong>DEB</strong> — installs the AppArmor profile with it. The safest choice on 24.04 and newer.
«ko»
<strong>AppImage</strong> — v0.6.0부터 정적 런타임으로 바뀌어 <code>libfuse.so.2</code>가 더 이상 필요 없습니다.
«t»
<strong>AppImage</strong> — moved to a static runtime in v0.6.0, so <code>libfuse.so.2</code> is no longer required.
«ko»
<strong>압축 패키지</strong> — 사용자 네임스페이스가 열려 있는 배포판에서 쓸 수 있습니다.
«t»
<strong>Archive package</strong> — for distributions where unprivileged user namespaces are available.
«ko»
<svg aria-hidden="true" class="note-ico" height="15" width="15"><use href="#i-danger"></use></svg>샌드박스를 끄지 않습니다
«t»
<svg aria-hidden="true" class="note-ico" height="15" width="15"><use href="#i-danger"></use></svg>The sandbox is never disabled
«ko»
ScriptPlayer+는 시스템 차원의 네임스페이스 제한을 만났을 때 <code>--no-sandbox</code>로 자동 우회하지 않습니다.
                포터블 AppImage나 압축 패키지가 실행되지 않는다면 DEB 패키지를 설치하세요.
«t»
