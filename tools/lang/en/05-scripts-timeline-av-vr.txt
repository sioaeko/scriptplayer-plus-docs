Same name, same folder
«ko»
가장 확실한 방법입니다. <code>영상.mp4</code> 옆에 <code>영상.funscript</code>를 두면 바로 잡힙니다.
«t»
The most reliable arrangement. Put <code>video.funscript</code> beside <code>video.mp4</code> and it is picked up at once.
«ko»
지정한 스크립트 폴더
«t»
The configured script folder
«ko»
스크립트를 따로 모아 뒀다면 <strong>설정 → 일반 → Script Storage Folder</strong>에서 그 폴더를 지정합니다.
                  (사이드바 <code>Folder</code> 옆의 작은 버튼으로도 지정할 수 있습니다.) 이후 그 폴더도 함께 검사합니다.
«t»
If you keep scripts apart, point <strong>Settings → General → Script Storage Folder</strong> at that folder.
                  (The small button beside <code>Folder</code> in the sidebar sets it too.) It is then scanned as well.

«t»
Even when the names do not match exactly, a candidate that narrows down to exactly one is selected for you.

Matching by duration<a aria-label="Link to this section" class="anchor" href="#sc-duration">#</a>
«ko»
이름이 전혀 다른데 내용은 맞는 스크립트를 찾아야 할 때가 있습니다.
              v0.6.0에 들어온 <strong>재생 시간 기반 검색</strong>은 스크립트 타임라인의 길이가
              영상 길이와 얼마나 비슷한지로 후보의 순위를 매깁니다.
«t»
Sometimes the right script has an entirely different name.
              The <strong>duration-based search</strong> added in v0.6.0 ranks candidates by how closely the
              script's timeline length matches the video's.
«ko»

«ko»
길이가 비슷한 순서로 정렬해 보여 주므로, 위쪽 후보부터 시도하면 됩니다.
«t»
Results are ordered by how close the lengths are, so work down from the top.

When the timing is off — script offset<a aria-label="Link to this section" class="anchor" href="#sc-offset">#</a>
«ko»
영상보다 움직임이 조금 빠르거나 느릴 때 씁니다.
              재생바의 <code>+0ms</code> 버튼을 눌러 조정합니다.
«t»
Use this when the motion runs slightly ahead of or behind the video.
              Adjust it from the <code>+0ms</code> button on the playback bar.
«ko»
범위는 <strong><code>-60초</code>부터 <code>+60초</code></strong>까지입니다.
«t»
The range is <strong><code>-60s</code> to <code>+60s</code></strong>.
«ko»
소수점 초 단위로 <strong>직접 입력</strong>할 수 있고, 미세 조정 버튼으로 조금씩 옮길 수도 있습니다.
«t»
You can <strong>type a value</strong> in decimal seconds, or nudge it with the fine-step buttons.
«ko»
오프셋은 <strong>미디어별로 저장</strong>되므로, 한 번 맞춰 두면 다음에 열 때도 유지됩니다.
«t»
The offset is <strong>stored per media file</strong>, so once you have it right it stays right.
«ko»
늘리기·줄이기·초기화 모두 단축키로 지정할 수 있습니다.
«t»
Increase, decrease and reset can all be bound to keys.
«ko»
오프셋 입력 창. 직접 값을 넣거나 버튼으로 미세 조정합니다.
«t»
The offset field. Type a value or nudge it with the buttons.
