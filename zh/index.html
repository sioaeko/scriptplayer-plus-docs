ScriptPlayer+ 使用手册

把电脑里的视频和音频与它们的脚本一起播放，并把动作输出到 The Handy、Intiface 和 FunOSR 设备的桌面播放器。本指南按顺序讲解，从安装一直到连接设备。

Windows · macOS · Linux · 本文档以 v0.6 系列为准。

安装

ScriptPlayer+ 从 GitHub Releases 上的 Windows、macOS 和 Linux 安装包安装。首次运行时系统可能弹出安全警告，下面一并给出处理方法。

下载#

所有构建都发布在 GitHub Releases 最新页面。请选择与你系统相符的文件。

平台安装包备注
Windows x64 安装程序（.exe）或便携版 .zip 若不想安装，下载便携版 ZIP 解压即可运行。
macOS x64 / arm64 .dmg 或 .zip Apple Silicon 与 Intel 的文件是分开的，请选与你机器相符的那个。
Linux x64 .deb · AppImage · 压缩包 Ubuntu / Kubuntu 24.04 及以上建议使用 DEB。

Windows#

  1. 运行安装程序

    运行下载的 .exe 会先显示最终用户许可协议（EULA）。确认并同意后安装继续。

  2. 如果 SmartScreen 弹出警告

    Windows 安装包没有 Authenticode 签名，因此 Microsoft Defender SmartScreen 可能显示“Windows 已保护你的电脑”之类的提示。点击更多信息 → 仍要运行即可继续安装。

  3. 使用便携版 ZIP 时

    直接运行解压后文件夹里的可执行文件。设置和缓存会保存在用户目录中。

macOS#

最低版本

从 v0.6.0 起 Electron 运行时升级，所需的最低 macOS 版本由 Big Sur 11 提高到 Monterey 12。Big Sur 无法运行 v0.6 及以后的版本。

  1. 打开 DMG 并移动应用

    打开 .dmg，把 ScriptPlayer+ 图标拖到应用程序文件夹。

  2. 如果提示“无法打开”

    Gatekeeper 可能提示无法验证开发者。进入系统设置 → 隐私与安全性，点击下方出现的“仍要打开”按钮即可运行。

Linux#

Ubuntu / Kubuntu 24.04 及以上建议使用 DEB 安装包。这些版本限制了非特权用户命名空间，而 Chromium 沙箱需要针对可执行文件的 AppArmor 配置，该配置只包含在 DEB 中。

  • DEB — 会一并安装 AppArmor 配置。在 24.04 及以上是最稳妥的选择。
  • AppImage — 从 v0.6.0 起改为静态运行时，不再需要 libfuse.so.2。
  • 压缩包 — 适用于用户命名空间可用的发行版。
不会关闭沙箱

遇到系统级的命名空间限制时，ScriptPlayer+ 不会用 --no-sandbox 自动绕过。如果便携版 AppImage 或压缩包无法启动，请改装 DEB。

更新#

有新版本时应用内会提示。可以直接从提示下载安装，同一版本号发布的热修复也会被识别。检查方式在设置 → 常规中调整。

5分钟上手

安装完成后从这里开始。五步之后视频就会播放、脚本会加载、设备会动起来。

五个步骤#

  1. 打开存放媒体的文件夹

    点左上角的 Folder 按钮，选择存放视频的文件夹。若只想快速看一个文件，也可以直接拖放到窗口里。

  2. 从列表中选择视频

    在侧边栏文件列表中点击文件即会立即开始播放。文件名右侧出现绿色文档图标，表示已找到匹配的脚本。

  3. 确认脚本已加载

    若视频下方能看到热力图色带和时间线图形，说明脚本已正确读取。若看不到，请用播放栏的 HM、TL 按钮打开。

  4. 连接设备

    点击左侧栏的设备图标，选择并连接你的设备。各设备的详细设置请参阅 The Handy、Intiface、FunOSR。

  5. 播放并调整力度

    按 Space 播放。若动作太强或太弱，在播放栏的 STR 中收窄或放宽行程范围。若时间对不上，用 +0ms 按钮调整偏移。

先了解这几点
  • 脚本通常放在与视频同一文件夹、同一文件名下就会被自动识别。（视频.mp4 ↔ 视频.funscript）
  • 如果脚本单独存放，请在设置中指定为脚本文件夹。
  • 第一次使用设备时，把行程范围调窄再开始更安全。

用媒体库代替逐个打开文件夹#

与其每次都去打开文件夹，不如把常用文件夹注册到媒体库，用缩略图卡片一览。从左侧栏最下方的媒体库图标开始。详情见媒体库。

界面导览

ScriptPlayer+ 的界面大致分为左侧栏、侧边栏、播放器和播放栏四部分。播放栏上那些简短的英文按钮最容易看不懂，下面全部列出。

左侧栏#

界面最左侧的窄竖条，用来选择侧边栏显示什么内容。自上而下依次为：

图标名称作用
文件打开文件夹、浏览文件列表的基本界面。最近播放列表也在这里。
脚本查找并替换当前媒体所匹配脚本的工具。
插件管理你自行安装的脚本来源插件。 → 插件
设备The Handy、FunOSR 等设备的连接与输出设置。 → The Handy
IntifaceIntiface / Buttplug 专用工作区。 → Intiface / Buttplug
媒体库以缩略图卡片呈现的媒体库。 → 媒体库
设置位于侧栏底部，也可以按Ctrl ,打开。→ 设置指南
折叠侧边栏

再点一次已选中的侧栏图标，侧边栏就会折叠，画面随之变宽。再点一次会展开。

侧边栏#

以文件界面为例，自上而下是这样排列的。

  • Folder — 打开媒体文件夹。旁边的小按钮用于指定脚本文件夹、载入或保存脚本、重新扫描。
  • Recent Media — 最近打开过的文件列表。条目旁的 × 逐个清除，垃圾桶图标全部清除。
  • Filter files… — 按文件名筛选。右侧数字是当前显示的文件数量。
  • Show multi-axis files only — 只显示有多轴脚本的文件。
  • Show rated files only — 只显示已评分的文件。
  • 排序 — 可按 Path（路径）以及名称、评分、时长、修改时间排序，并用 Asc/Desc 切换方向。
  • Script Variants — 当前媒体匹配到多个脚本时用来选择的面板。 → 使用脚本
  • 文件列表 — 有脚本的文件会带一个绿色文档图标。

播放栏按钮词典#

界面最下面一行。左侧是播放控制，右侧是画面与脚本相关的开关。各英文缩写含义如下。

1x播放速度 — 用两侧的 − + 调整倍速。
STR行程（Stroke） — 就地收窄或放宽设备的运动范围。反转开关也在这里。
+0ms脚本偏移 — 把动作相对视频前移或后移，可在 -60秒 ～ +60秒 范围内调整。
AB区间循环 — 标记 A 点和 B 点，只循环这一段。
循环 — 只重复当前正在播放的这个文件。自动跳到下一个文件是另一个 Auto Next Play 设置。
随机播放 — 以随机顺序播放列表。
EXT外部播放器（External） — 用 mpv、VLC 等外部播放器打开该文件。 → 外部播放器
TL时间线（Timeline） — 显示或隐藏脚本图形。
HM热力图（Heatmap） — 用色带显示整个文件的强弱。
AV音轨与字幕轨 — 选择内嵌音轨和字幕轨。 → 音频与字幕
评分 — 不离开播放界面就能打分。媒体库的排序和筛选会用到。
FIT适应 — 缩放到能看到整个画面。可能出现黑边。
FILL填充 — 无黑边铺满画面。画面边缘可能被裁掉。
全屏 — 与 F 键相同。
提示

打开 VR 或 360 度视频时，播放栏还会出现投影方式按钮。 → VR 与 360 度视频

标题栏#

窗口最上方显示应用名和版本，右侧有 Stop all devices 按钮。这是一次停止所有已连接设备的紧急停止按钮。 → 安全与紧急停止

媒体库

文件一多，逐个打开文件夹就很麻烦。媒体库让你注册常用文件夹，用缩略图卡片一次浏览。

注册多个文件夹#

从 v0.6.0 起可以注册多个带名称的媒体库文件夹，在设置 → 常规的 Library folders 中管理。每个文件夹独立处理，关掉一个不影响其余。

  • Add folder — 添加文件夹。选择对话框可一次选多个。
  • 名称 — 用 Local Library、NAS Library 这类易读的名字代替路径。
  • 开关 — 想暂时排除时关掉即可。关闭的文件夹会保留其设置，只是不再参与扫描。
  • 垃圾桶 — 仅解除注册，不会删除实际文件。
脚本文件夹也在这里

用来存放已下载脚本的 Script Storage Folder 也在同一界面指定。设定之后，脚本自动匹配和插件下载都会使用这个文件夹。 → 使用脚本

使用 NAS 时

本地与 NAS 的目录会在缓存中合并成一份去重后的列表。启动时先显示缓存内容，然后逐个依次刷新各文件夹。由于不会同时读取多个文件夹，启动时磁盘与网络的压力不会集中爆发。

筛选与排序#

筛选条件会被保存，下次打开时依然生效。

功能说明
搜索按标题和路径查找。
媒体类型分为只看视频 / 只看音频。
脚本分类可分别筛选单轴脚本和多轴脚本。
评分只显示已打分的条目。
排序按路径、文件名、评分、时长或修改时间排序。

按时长排序需要先知道长度，这会在后台自动扫描。文件较多时一开始只显示一部分，随后逐渐填满。

使用卡片#

  • 卡片尺寸 — 用滑块调整一屏显示的数量。
  • 缩略图菜单 — 可直接在卡片上更换或重新生成封面图。
  • 评分 — 在卡片上打分，播放中也能用播放栏的 ☆ 修改。

悬停预览#

把鼠标停在文件列表的条目上，就会无需打开文件播放一段短视频预览。不必再为确认内容而逐个打开。

播放

循环 · 自动播放下一个 · 随机#

看起来相似但其实是三件不同的事。刚开始容易混淆，所以分开说明。

循环 🔁

只重复当前正在播放的这个文件。

Auto Next Play

文件结束后自动跳到下一个文件。在设置中开启。

随机 🔀

以随机顺序播放列表。

AB 区间循环#

想反复观看视频某一段时使用。标记起点（A）和终点（B）后，只有这一段会循环。

  1. 在想循环区间的起始位置设定 A 点。
  2. 在区间的结束位置设定 B 点。
  3. 区间循环随即开始。打开编辑器可把两点调到精确数值。

设定 A、B 以及打开编辑器都可以绑定快捷键。（键盘快捷键）

画面适应 — FIT 与 FILL#

当视频比例与窗口比例不同时，用来决定优先哪一边的按钮。

  • FIT — 缩放到能看到整个画面。上下或左右可能出现黑边。
  • FILL — 铺满整个画面。画面边缘可能被裁掉。

全屏#

按 F 进入全屏。全屏下仍可唤出侧边栏，不必为换文件而退出。

从 v0.6.0 起可在设置中更改全屏控件的显示方式。

  • 仅从底部边缘出现 — 这样在画面任意处移动鼠标都不会唤出控件。
  • 背景不透明度 — 让控件背后的底色更深或更浅。
  • 竖直位置 — 调整控件出现的高度。

窗口置顶#

想一边用别的窗口一边继续看播放画面时，可以把窗口固定在最前面。

重置与恢复#

如果改了太多设置而弄乱了，可以在设置 → 恢复里回到初始状态。整体重置还会一并清理缓存的时长、行程范围，以及播放器、媒体库、工作区、最近媒体和侧边栏的状态。

使用脚本

脚本没被自动识别、识别了但时间对不上、动作太强——这些情况该动哪里，都整理在这里。这一页基本能解决大部分脚本问题。

脚本是怎么被找到的#

ScriptPlayer+ 按以下顺序查找匹配的脚本。

  1. 同一文件夹、同一文件名

    最可靠的做法。把 视频.funscript 放在 视频.mp4 旁边即会立刻识别。

  2. 指定的脚本文件夹

    若脚本单独存放，请在设置 → 常规 → Script Storage Folder 中指定该文件夹。（侧边栏 Folder 旁的小按钮也能指定。）之后该文件夹也会一并扫描。

  3. 媒体库收录的脚本

    已注册的媒体库文件夹所索引的脚本也会作为候选。

  4. 只有一个候选时自动选择

    即使名称并不完全相同，只要能明确收敛到一个，也会自动为你选中。

脚本变体面板#

同一视频有时会匹配到多个脚本，像 Soft 这种用括号标注的变体最为常见。这时可在侧边栏的 Script Variants 面板中不停止播放直接替换。

按时长查找#

有时需要找名称完全不同但内容对得上的脚本。v0.6.0 引入的按时长搜索会根据脚本时间线长度与视频长度的接近程度为候选排序。

  • 会把视频所在文件夹、指定的脚本文件夹以及媒体库已索引的脚本都作为候选。
  • 结果按长度接近程度排列，从上往下试即可。

时间对不上时 — 脚本偏移#

正值（+）使动作提前，负值（-）使动作延后。如果动作比视频晚约0.2秒，就在当前值上加0.2秒；如果早约0.2秒，就减去0.2秒。输入框以秒为单位：0.2秒 = 200ms。

当动作比视频稍快或稍慢时使用。点播放栏的 +0ms 按钮进行调整。

  • 范围是 -60秒到+60秒。
  • 可以按小数秒直接输入，也能用微调按钮一点点挪动。
  • 偏移量优先按脚本保存，否则按媒体文件保存。再次使用同一脚本时，可能会应用已保存的偏移量。
  • 增大、减小和重置都可以绑定快捷键。
对齐技巧

先跳到有明显动作的位置，一边播放一边小幅调整偏移。当时间线图形的波峰与画面里的动作重合时，就对了。

动作太强时 — 行程范围#

播放栏的 STR 用来调整设备实际运动的范围。无需修改脚本就能降低或提高力度。

同样的设置也可以在设置 → 设备中更细致地调整。

项目作用
Stroke Range Min / Max在 0%～100% 之间设定运动的下限与上限。
Range Extender在应用最终行程范围之前，以 50% 中心为基准放大或缩小 L0 的运动。
Inverse Stroke在发送到设备之前，把脚本的位置数值上下翻转。
Amplitude setting behavior v0.6.0选择这个数值是按脚本分别记住，还是在所有媒体间共用一份。
保持中心的范围 v0.6.0像旋转轴这种以中心为基准的轴，会保持中心不变，只收窄幅度。
初次使用时

先把范围调窄再开始，熟悉之后逐步放宽。配合速度限制会更安全。 → 安全与紧急停止

处理空白区间#

当脚本中存在较长的无动作区间时使用的选项。

  • 间隙填充（Fill gaps） — 用生成的动作填补空白区间。
  • 自动跳过 — 跳过空白区间。可以设置延迟，让它稍等一会儿再跳，而不是立刻跳过。
  • 稀疏脚本补正 — 把点位稀疏的脚本整理得更平滑。

完全没有脚本时 — 随机行程#

即使视频没有脚本，也能生成动作。预设中把基础的挑逗模式与更强的模式分开了。

生成的动作可在 Off、Light、Balanced、Strong 之间选择平滑度。方向不会突然折返，而是走加减速曲线，因此自然得多。

从视频生成脚本# 实验功能

从 v0.4.0 起，可以分析视频中的动作生成脚本并保存在媒体旁边。分析需要外部的 FFmpeg 可执行文件。 → FFmpeg 兼容播放

提示

运动分析属于实验功能。结果质量随视频差异很大，生成的脚本可能需要手动修整。

多轴脚本#

同时驱动多个轴的脚本支持以下三种形式。

  • 在一个文件中用 axes[] 收纳各轴
  • 在一个文件中用 channels{} 收纳各轴
  • 每个轴一个文件（例如 视频.L0.funscript、视频.R0.funscript）

从 v0.6.0 起可以按轴替换脚本来源。例如沿用多轴包，但只把 L0 轴换成另一个文件。也支持从别的轴取值的轴来源联动（例如 L0 → R0）。

在界面上查看多轴脚本的方法见时间线与热力图。

检查脚本#

脚本表现异常时，有一个界面可以查看实际传入的数值。

时间线与热力图

查看脚本的两种方式。时间线显示当下这一刻，热力图显示整个文件。

时间线 TL#

随播放位置滚动的实时图形。用播放栏的 TL 按钮开关。

选择轴

打开多轴脚本后，时间线上方会出现 AXES 一行。

  • All — 把所有轴一次叠加显示。
  • 轴按钮（L0、L1、R0、R1 …） — 逐个开关。按钮旁的数字是该轴当前的数值。
  • 双击 — 只保留该轴、隐藏其余。想仔细看某一个轴时很方便。

调整高度

上下拖动视频与时间线之间的分隔线即可改变时间线高度。轴较多时拉宽会好看很多。

热力图 HM#

把整个文件压缩成一条横向色带。颜色代表速度 — 绿色较慢，经过黄色越往红色越快。

播放前就能知道哪里是激烈段落，想直接跳到某处时很有用。

提示

媒体库列表和卡片上不显示热力图。热力图只在播放界面可见。

时间线设置#

设置 → 时间线中可以调整以下项目。

  • 显示对比度 — 让图形更深或更浅
  • 按速度着色的开 / 关
  • 默认高度

音频与字幕

关于声音和字幕的内容：音频文件播放、音量增强、载入字幕以及选择内嵌轨道。

播放音频文件#

MP3、FLAC 这类音频也能像视频一样附上脚本播放。因为没有画面，会改为显示封面图。

封面图按以下顺序查找。

  • 音频文件内元数据中的图片
  • 同一作品文件夹内的图片文件

音量增强 150%# 实验功能

针对录音过小、听不清的音源，音量最多可提升到150%。同时会启用峰值限制器，防止突然爆音。

注意

如果你戴着耳机，请先把音量调低再开启增强。

字幕#

外部字幕文件

支持 .srt、.vtt、.txt。与视频同名时会自动找到并载入。若未自动识别，也可以手动载入。

内嵌字幕

视频文件内的文本字幕轨也可以使用，从播放栏的 AV 按钮选择。不过必须已安装外部 FFmpeg。

字幕类型是否支持
SRT, ASS/SSA, WebVTT, mov_text支持 — 属于文本类轨道。
PGS、DVD 字幕会列出但无法显示。它们是图像类字幕，不做渲染。

选择音轨#

如果文件内含多语言音频，可从 AV 按钮选择音轨。该功能同样需要外部 FFmpeg。 → FFmpeg 兼容播放

VR 与 360 度视频

打开 VR180 或 360 度视频时，画面会不自然地拉伸或分成两半。指定投影方式后就能正常观看。 v0.6.0

支持的投影方式#

方式适用于哪种视频
360 度等距圆柱
(Equirectangular)		拍摄了全方位的视频。平铺展开后看起来像世界地图。
VR180 等距圆柱只拍摄了前方 180 度的视频。在 VR 视频中最常见。
180 度等距鱼眼
(Fisheye)		以中心凸起的圆形拍摄的视频。

选择源画面布局#

即使投影方式相同，两眼画面的排布方式也可能不同。

  • 单目（Mono） — 一屏中只有一个画面。
  • 左右分割（SBS） — 左右各放一只眼的画面。不指定就会看到分成两半。
  • 上下分割（Top-and-Bottom） — 上下各放一只眼的画面。

对 SBS 和上下分割的视频，可以选择观看哪只眼。

观看操作#

  • 拖动 — 用鼠标拖动转动视角。
  • 放大 / 缩小 — 拉近或推远来调整视场角。
值得了解的限制
  • 在桌面画面上，SBS 与上下分割的视频一次只显示一只眼。
  • 不支持向头显输出的 WebXR 立体显示。
  • 不包含拼接双鱼眼 360 度视频的功能，也不含按镜头的鱼眼校准。
  • 无法应用投影的视频会自动回退到平面播放，画面不会出错。

The Handy

The Handy 通过互联网工作。它把脚本上传到服务器并对齐播放时刻，因此连接质量会直接影响体感。

连接#

  1. 查看连接密钥

    在 The Handy 机身屏幕或其应用中查看连接密钥（Connection Key）。

  2. 在设置 → 设备中输入

    在 ScriptPlayer+ 的设置 → 设备中选择 The Handy 并填入连接密钥。

  3. 确认连接

    连接成功后状态显示会变化。播放视频时脚本会自动上传并同步。

同步与时间偏移#

The Handy 使用 API v2。开始播放时会上传脚本，并按服务器时钟同步播放位置。

上传完成后自动播放

开启设置 → 播放中的 Auto Play After Handy Sync，上传与 HSSP 同步一结束就会立即开始播放，不必每次等同步完成再去按播放。

如果整体上动作偏早或偏晚，用时间偏移校正。若只有某个视频对不上，多半是脚本本身的问题，请改用脚本偏移。

网络诊断#

在设置 → Handy 网络诊断中可以实测连接质量。若动作总是卡顿或延迟，请从这里开始排查。

项目含义
延迟中位数正常情况下的往返时间。越低越好。
P95 延迟较慢那 5% 的延迟。该值偏大说明偶尔会大幅波动。
抖动延迟的波动程度。越大同步越不稳定。
成功率请求正常往返的比例。
服务器时钟偏差你的电脑时钟与服务器时钟之间的差值。
分享诊断结果

诊断结果可以复制后附在反馈里，这样说明问题会轻松得多。

兼容模式#

为较旧的硬件或响应较慢的设备提供了兼容模式。若默认设置下表现不稳定，可以试着开启。

Intiface / Buttplug

Intiface 是把多家厂商的设备统一到同一规范的中继软件。从 v0.6.0 起 ScriptPlayer+ 内置了专用工作区，不必在多个窗口间来回切换。

两种连接方式#

内置引擎

使用 ScriptPlayer+ 内含的轻量引擎。无需额外安装，最为简便。

外部 Intiface Central

连接到你已在使用的 Intiface Central，可以支持更多设备和设置。

连接#

点击左侧栏的 Intiface 图标会打开 Intiface Device Manager。界面上方显示 1 Connect → 2 Find device → 3 Configure → 4 Playback 四个步骤，并同时告知当前处于哪一步、下一步该做什么。

  1. Connect — 选择连接方式

    在 Built-in engine 与 External Central 之间选择。用内置引擎会显示地址（ws://127.0.0.1:…），选外部则需填入要连接的地址。

  2. Find device — 搜索设备

    开始扫描后会查找 Bluetooth、HID 以及已配置的串口设备。请让设备保持开机、处于待配对状态并稍等。可以同时选中多台设备。

  3. Configure — 输出映射

    在 Output mapping 中选择设备，并指定每个可用功能对应哪个脚本轴。

  4. Playback — 播放

    播放视频后就会按映射的轴输出。电池电量也能在此界面查看。

连接状态也会在侧栏图标上显示为未连接、处理中、已连接、错误。

功能映射#

Buttplug 设备的功能分为三类，每一类都可以绑定到你想要的轴。

  • 线性（Linear） — 前后往复的动作，通常绑定 L0 轴。
  • 旋转（Rotate） — 转动的动作，通常绑定 R0 轴。
  • 标量（Scalar） — 像振动强度这样用单一数值表示的动作。

如果需要脚本里没有的轴，可以用轴来源联动从别的轴取值。例如把 L0 的动作用作 R0 的输出。

与其他应用共用#

内置引擎一次只接一个

内置的 Intiface 引擎一次只接受一个 Buttplug 客户端。ScriptPlayer+ 与其他应用无法同时控制它。

因此提供了移交功能。点击 Intiface Device Manager 中的 Allow FapTap / external app 按钮，引擎会继续运行，而只有 ScriptPlayer+ 放开连接。期间 FapTap 等其他客户端可以连到同一地址；该应用断开后，ScriptPlayer+ 会重新连接。

顺序很重要

先启动其他应用、再想把 ScriptPlayer+ 接上，是会失败的。请先从 ScriptPlayer+ 放开连接，然后再连接其他应用。

按设备的看门狗#

使用多台设备时，若其中一台变慢或反复失败，过去会把其他设备一起拖住。从 v0.6.0 起每台设备都有独立的看门狗，一台出问题不会阻塞其余设备的输出。

Windows 内置引擎的范围#

Windows 版内置引擎可处理的连接如下。

  • Bluetooth LE
  • HID
  • 一个显式指定的 Bluetooth RFCOMM COM 端口 — 按 TCode v0.3、115200 波特率映射。
该串口路径的限制

该路径只暴露 FunOSR SR1 使用的单一线性轴定义。如果需要 USB 串口适配器或 SR6 的完整多轴串口映射，请直接使用FunOSR 提供方或外部 Intiface Central。

FunOSR

FunOSR 直接向串口（COM）发送信号。不经过中继软件，延迟更低，也能更细致地处理多轴映射。

选择端口#

在设置 → 设备中选择 FunOSR 并指定 COM 端口。从 v0.6.0 起端口识别有所改进，会按以下顺序优先推荐合适的端口。

  1. 被明确识别为 FunOSR 的端口
  2. CH340 / CH341 适配器
  3. USB 标识 1A86:7523
端口暂时看不到也不要紧

即使启动时搜索结果为空，已保存的 COM 路径依然保留。设备插得晚也不会丢失设置。

调整输出#

在设置 → 设备中调整以下项目。

项目说明
更新速率决定每秒发送多少次指令。设得过高反而可能不稳定。
轴映射把脚本的轴与设备的实际轴对应起来。
运动平滑把动作整理得更平滑。
Custom speed limit以 spm（每分钟完整行程次数）为单位限制各轴的最高速度。也可以选择该轴是沿用全局限制还是单独设置。
Pause / Stop Behavior决定播放暂停、停止或切换媒体时设备的行为。（例如 Return home — 回到原位）
Home Return Speed回到原位的速度。数值越大回得越慢。
Playback Start Safety开始播放时，FunOSR / SR 设备会用这段时间缓慢移动到脚本位置，然后才进入正常输出。设为 0 则关闭。
重新连接连接断开时自动重连。

轴测试与居中#

要确认轴是否接对，并不需要播放视频。在设置 → 设备最下方的 Device Test Panel 中点击 L0、V0、V1、R0 按钮，就能直接向该轴发送一条短指令。Stop 可立即停止，居中指令会让它回到中间。

确认轴是否接反了

如果按 L0 却是旋转在动，说明轴映射错了。用这个面板逐个按一遍，立刻就能知道哪个轴接到了哪里。

想确认脚本究竟来自哪个文件、是怎么读取的，请开启 Show Script Debug Info。播放界面会显示脚本路径、来源、轴列表和已保存的偏移。

SR1 相关选项#

  • Bluetooth COM 输出 — 应用 25Hz 上限与 TCode 插值，让输出更顺滑。空闲时不发送保持信号。
  • SR1 2.0 Twist 静音模式 — 调整 R0 旋转速度上限以降低噪音。

暂停与继续#

串口发送延迟后再继续播放，设备可能因为要一次追回落后的量而大幅跳动。v0.5.1 与 v0.6.0 加强了这一部分。

  • 只要设定的安全启动时间过去，继续播放的过渡就一定会结束。
  • 落后的进度会设有上限地追回，因此不会出现大跳。
  • 修复了卡在安全过渡状态、无法回到脚本的问题。

手机与手柄遥控

可以用专用蓝牙遥控器或手机操作播放。适合不想伸手去按键盘就完成播放、暂停、切换下一个文件的场景。

连接前的准备#

Android手机：通过设置中的Get Android app安装应用，然后在手机上打开遥控页面。开启蓝牙并允许应用请求的附近设备权限。打开遥控页面上的BLE开关，使手机进入等待连接状态，并记下显示的设备名称。

专用遥控器：开启已安装受支持固件的设备。如果需要安装固件，请先通过设置中的Open flasher按对应设备的说明操作。也要开启电脑蓝牙，然后执行下方配对步骤。

配对#

  1. 打开设置

    进入设置 → 手机/手柄遥控。

  2. 连接

    在电脑上点击Connect，然后在设备选择窗口中选择手机上显示的名称或专用遥控器。

  3. 输入 6 位验证码

    输入遥控器屏幕上显示的6 位配对码，然后点 Pair。

配对完成后会显示状态、固件、电池和令牌信息。配对过一次的遥控器之后会自动重连。

按键映射#

A、B、C 三个按键可以分别设定单击、双击、长按的动作。默认值如下。

按键单击双击长按
A播放 / 暂停无无
B下一个视频无无
C上一个视频无无
因设备而异

在 M5Stick S3 这类缺少部分按键的设备上，不支持的映射既不会出现在列表中，也不会被发送。

应用与固件#

  • Get Android app — 前往把手机当作遥控器使用的应用。
  • Open flasher — 打开为遥控设备刷写固件的工具。

安全与紧急停止

既然要用设备，就必须随时能立刻让它停下。本页讲的是停止的方法，以及可以事先设定的限制。如果这是你第一次使用设备，请先读这一页。

全局紧急停止（E-Stop）# v0.6.0

窗口右上角的 Stop all devices 按钮。无论当前选用哪个提供方，它都会向所有已连接的设备发送停止请求。

  • 它会停止播放，并向 Handy、Intiface、FunOSR 全部发送停止指令。
  • 停止请求有时限，不会无限等待。
  • 失败或超时的设备会留在列表中，可以重试。

该按钮会在设备已连接时出现在标题栏和全屏界面。是否显示可在设置 → 设备的 Show E-Stop button 中关闭。

隐藏按钮之前

即使隐藏，Intiface 管理界面中的停止控件依然保留。但那边需要先切换界面才能到达。隐藏之前请务必确认它的位置。

事先设定的限制#

防止意外的最好办法，是一开始就不让它动得太猛。

行程范围
用播放栏的 STR 收窄运动幅度。一开始请调窄。 → 使用脚本
Custom speed limit
以 spm 为单位限制各轴的最高速度。在 FunOSR 上尤其有用。 → FunOSR
Playback Start Safety
开始播放时不会立刻全速，而是在指定时间内缓慢移动到脚本位置。
保持中心的范围
像旋转轴这种以中心为基准的轴，会保持中心不变，只收窄幅度。

一次只用一个提供方#

当前限制

设备输出一次只使用一个提供方。目前还不支持同时向 Handy 和 Intiface / FunOSR 输出。

切换提供方时，会在旧连接清理完成后再接上新连接。v0.6.0 修复了从 FunOSR 切到 Handy 或 Intiface 时被清理流程卡住的问题。

建议的习惯#

  • 第一次播放新脚本时，先把范围调窄，看看动作是什么样的。
  • 先在热力图上确认红色区段在哪里。 → 时间线与热力图
  • 让手记住 E-Stop 按钮的位置。
  • 不要让设备开着就离开座位。

准备方法#

ScriptPlayer+ 按以下顺序查找 FFmpeg，满足其中任意一项即可。

  1. 从设置中自动安装 最简单

    可以通过设置界面的按钮，用系统的包管理器安装。Windows 用 winget，macOS 用 Homebrew，Linux 使用受支持的包管理器。只有你亲自点击时才会执行。

  2. 环境变量 FFMPEG_PATH

    把可执行文件路径写进这个环境变量，就会使用它。

  3. 常见安装路径或系统 PATH

    如果已经安装了 FFmpeg，通常会自动找到。

  4. 自行选择

    在设置中直接指定 FFmpeg 可执行文件。自动搜索失败时最可靠的办法。

选择兼容模式#

在设置 → 播放的 Video Compatibility Mode 中决定介入程度。请按症状选择。

症状应选
播放正常Auto — 只在需要时自动介入。这是默认值。
有画面但没声音音频兼容模式 — 只用 FFmpeg 处理声音。
画面全黑或根本打不开完全兼容模式 — 连视频也用 FFmpeg 处理。
更改后需要重新打开

更改兼容模式后，需要关闭视频再重新打开才会生效。

为什么不随包提供

ScriptPlayer+ 的发布包中不含 FFmpeg 可执行文件，也不含 FFmpeg 源码。兼容播放、缩略图备用生成与运动分析都只使用外部可执行文件。

插件

自行添加脚本来源的功能。默认不包含、也不推荐任何提供方。需要时由你自己安装使用。

什么是 .funplugin#

.funplugin 文件只是一个 JSON 清单。里面只包含到哪里查找脚本的信息，不含任何可执行代码。

不会执行代码

ScriptPlayer+ 不会在应用内运行插件的代码。因为只读取纯数据清单，插件无法擅自操控应用。

安装与管理#

在左侧栏的插件图标中管理。安装时会验证以下内容。

  • 清单校验 — 严格检查格式是否正确。
  • 权限确认 — 显示它请求了什么。
  • 签名 — 若发布者提供了签名则进行验证。（可选）
  • 信任信息展示 — 把以上结果呈现给用户查看。

下载的脚本#

通过插件获取的脚本会保存到你指定的脚本文件夹；若未指定，则保存到应用管理的目录。下载完成后会立即应用到当前正在播放的媒体。

同时下载多个时，各自的进度会分别显示。

疑难解答

收集了常见症状与排查顺序。请从上往下依次尝试。

安装与启动#

Windows 上出现“已保护你的电脑”警告

这是因为 Windows 安装包没有 Authenticode 签名，SmartScreen 才给出的提示。点击更多信息 → 仍要运行即可安装。

macOS 上应用打不开

请在系统设置 → 隐私与安全性中点击“仍要打开”。也请确认你的系统为 macOS Monterey 12 或更高。

Linux 上无法启动

如果是 Ubuntu / Kubuntu 24.04 及以上，请安装 DEB 包。AppImage 与压缩包无法绕过系统的用户命名空间限制，而 ScriptPlayer+ 也不会用 --no-sandbox 自动启动。

播放#

视频打不开，或者只有声音

  1. 先确认扩展名在支持列表中。 → 支持的文件格式
  2. 容器对得上但编码格式可能不同。请准备 FFmpeg 并开启兼容播放。
  3. 若仍然不行，试着用外部播放器打开。

VR 视频显示成两半

这是左右分割（SBS）的视频被按平面播放了。请把投影方式设为 VR180 等距圆柱，源画面布局设为左右分割。 → VR 与 360 度视频

缩略图生成不出来

这是 Chromium 无法解码该视频的情况。只要有 FFmpeg，就会用备用方式生成缩略图。

脚本#

脚本没有被自动识别

  1. 确认脚本与视频在同一文件夹、同一文件名。
  2. 如果单独存放，请在侧边栏指定脚本文件夹。
  3. 在侧边栏点一下重新扫描。
  4. 如果名称完全不同，请使用按时长查找。

动作比视频快或慢

通过播放栏的+0ms调整脚本偏移。动作晚了就增大数值，早了就减小。优先按脚本保存，否则按媒体文件保存。如果所有媒体都存在相同延迟，也请检查设备的时间偏移。→ The Handy

识别到了，但我想用另一个脚本

可以在侧边栏的 Script Variants 面板中替换。 → 使用脚本

设备#

设备完全不动

  1. 确认脚本确实已加载。能看到时间线图形吗？
  2. 确认设备的连接状态是已连接。
  3. 确认行程范围没有被收窄到接近 0。 → 使用脚本
  4. 确认没有仍处于紧急停止状态。 → 安全与紧急停止
  5. 如果是 FunOSR，用实时轴测试看硬件本身是否有反应。

动作卡顿或延迟

  • The Handy — 运行网络诊断查看延迟与抖动。数值不佳时请尝试有线连接或换一个网络。
  • FunOSR — 试着降低更新速率。设得过高反而更不稳定。
  • Intiface — 如果同时用了多台设备，请只留一台再试。

无法切换到别的设备

输出一次只使用一个提供方。清理上一个连接可能需要一点时间，请等几秒再试。 → 安全与紧急停止

其他应用找不到 Intiface 设备

内置的 Intiface 引擎只接受一个客户端。请用 Intiface 管理界面的移交控件把控制权交出去。 → Intiface / Buttplug

以上都不管用时#

  1. 在设置 → 恢复中尝试重置。 → 播放
  2. 确认是否为最新版本。 → 安装
  3. 到 GitHub Issues 提问。如果是设备问题，复制诊断信息一起附上会快得多。
